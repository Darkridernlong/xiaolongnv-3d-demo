# 龙女奇遇记 · 3D Demo（v05g）

终南山月夜试玩。打开本仓库的 [GitHub Pages](https://darkridernlong.github.io/xiaolongnv-3d-demo/) 即可在浏览器里玩（需能访问 unpkg，用于加载 three.js 0.160.0）。

本地试玩：在本目录启动一个静态服务器（不要直接双击打开，以免部分资源被浏览器拦截），例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 操作

- **WASD / 方向键**：移动（相对镜头方向）
- **Shift**：疾行（疾行中按 J 可出「惊鸿游龙」）
- **空格**：跳跃 / 轻功（10 级领悟二段跳，15 级可按住空格滑翔）
- **鼠标拖动**：旋转镜头；滚轮缩放
- **J / 鼠标左键短按**：玉女剑法普通攻击（连按成招：①冷月斜晖 ②回风拂雪 ③彩凤回翔）
- **K**：绝招。1 级起即可使用「玉女剑法·剑气横扫」（冷却约 3 秒，消耗约 28% 内力）。连按可按等级领悟后续绝招连环
- **L**：按原先规则释放当前已冷却、等级最高的绝招
- **C**：角色 / 招式面板
- **Tab**：打开面板并翻页
- **M**：地图
- **Esc**：关闭地图或对话框

第一次按键或点击后才会开始播放配乐。右下角可调「乐 / 效」音量，或点「音」静音。

进度会保存在浏览器本地（存档键：`longnv_3d_demo_v05g`）。
